# Gestionale Torronificio

App del Torronificio delle Madonie (Blufi).

Qui c'è solo il "guscio" dell'app, che le permette di aprirsi anche senza segnale.
I dati (registrazioni HACCP, clienti, DDT, magazzino) **non sono qui**: restano nel Foglio Google della titolare e si vedono solo entrando con il PIN da un dispositivo abilitato.
